# 🏛️ 한국공학대학교(TUKOREA) R&D 혁신 성과 포털

> **"산업 현장과 미래 기술을 잇는 산학일체형 공학 연구 허브"**  
> 대한민국 대표 산학협력 특성화 대학인 **한국공학대학교 (Tech University of Korea)**의 최근 우수 연구 성과, 5대 미래 첨단 클러스터(5T ICC), 보유 특허 및 기술이전 마켓플레이스를 체계적으로 소개하는 현대적인 SPA 웹 애플리케이션입니다.

## 🌟 주요 기능 및 구성

### 1. R&D 임팩트 메트릭 & 대시보드 (Hero Metrics)
- **최근 연간 R&D 연구비**: 1,320억 원+ (+18.4% YoY)
- **가족회사 및 협력기업**: 4,500여 개사 (누적 11,000+ 네트워크)
- **보유 핵심 특허**: 1,580건+ (해외특허 180건 포함)
- **기술이전 및 사업화 누적 실적**: 342억 원
- **주요 대형 국책사업 유치**: 14개 사업단 (총 1,200억 원 규모)

### 2. 5대 첨단 연구 클러스터 (5T ICC) 최신 연구 성과
- **차세대 반도체·패키징**:
  - 남옥현 교수팀: 세계 최초 단결정 다이아몬드 웨이퍼 기반 Monolithic 트랜지스터(E/D-모드 동시 구현, APWS 초청)
  - 김수민 교수팀: AI 기반 레이저 스펙클(Speckle) 노이즈 저감 기술 (브라이튼코퍼레이션 기술이전)
  - 반월시화 공정혁신 시뮬레이션 센터: 고부가 3D 패키징 휨(Warpage) 예측 가상 트윈 플랫폼
- **AI 제조혁신·자율로봇**:
  - 김효영 교수팀: 반도체 설비 및 산업용 로봇 예지보전 AI 자율진단 시스템 (대한기계학회 백암논문상 수상)
  - 박성원 교수팀: 미션 크리티컬 산업망 무중단 이중화 OS (티데이트 기술이전)
  - 이낙범 교수팀: 무인판매 키오스크 비접촉 멀티모달 제스처 인터페이스 (원퍼스트글로벌 기술이전)
  - 배유석 교수팀: 산자부 280억 규모 '반월시화형 AI 제조혁신 실증 AX 허브' 출범
- **미래 모빌리티·전력제어**:
  - 정명진 교수팀: 전기차 배터리팩 열폭주 180초 사전감지 다중 광섬유 센싱 시스템
- **탄소중립·그린에너지**:
  - 이강원 교수팀: 그린수소 생산 수전해용 고내구성 비귀금속 나노촉매 전극
  - 최호석 교수팀: 스마트산단 배출 폐열 회수용 초고효율 나노복합재 열전발전 모듈
- **첨단 바이오·나노융합**:
  - 심진형·진송완 교수팀(3D 바이오프린팅 연구소): 혈관화 인공장기 및 피부 독성 평가 모델 (Advanced Healthcare Materials 게재)
  - 한은비 교수팀: 무통증 생분해성 마이크로니들 기반 실시간 대사지표 모니터링 스마트 패치

### 3. 인터랙티브 데이터 시각화 (Chart.js)
- **연구비 수주 추이 차트**: 2021~2026 연도별 정부 국책과제 및 민간 산학공동 R&D 수주 추이 (다중 곡선 및 면적 차트)
- **5대 분야별 특허 비중**: 도넛 차트
- **기술성숙도(TRL) 단계별 파이프라인**: 1~9단계 수평 막대 차트

### 4. 특허 및 기술이전 마켓플레이스 (Tech Transfer Market)
- 기업이 즉시 도입 가능한 유망 원천 특허 목록 및 이전 조건 공개
- 원클릭 **"기술이전 및 산학공동 R&D 상담 신청"** 온라인 접수 폼 (접수번호 발급 및 로컬 저장)
- 기술이전 4단계 표준 프로세스 안내

### 5. 우수 연구자 & 랩 디렉토리 (Faculty & Labs)
- 주요 연구책임자의 프로필, 연구실 링크, 대표 연구분야, 논문/특허 실적 카드

### 6. 대형 국책 연구센터 & 인프라
- 산자부 280억 AX 허브, 나노반도체융합센터(클린룸 1,200m²), 공정혁신 시뮬레이션 센터, 3D 바이오프린팅 연구소, 고부가 PCB 공동연구센터

### 7. UX & 편의 기능
- **실시간 통합 검색**: `Ctrl + K` 단축키 지원, 타이핑 즉시 필터링
- **스크랩 보관함**: 관심 기술 북마크 저장 및 관리
- **TRL 레벨 필터링**: 기초(1~3), 응용(4~5), 실증(6~7), 상용화(8~9) 단계별 탐색
- **다크 모드 / 라이트 모드 전환**: 상단 해/달 아이콘 클릭
- **다국어 지원**: 한국어 / English 토글
- **성과 요약서 인쇄 및 PDF 저장**: 모달 내 인쇄 전용 CSS 적용

## 🚀 실행 방법

### 방법 1: 원클릭 배치 파일 실행 (가장 추천)
폴더 내의 **`start.bat`** 파일을 더블클릭하면 로컬 웹 서버가 가동되며 브라우저(`http://localhost:8080`)가 자동으로 열립니다.

### 방법 2: PowerShell 명령어로 실행
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```

### 방법 3: 직접 브라우저로 열기
별도의 웹 서버 없이도 폴더 내의 **`index.html`** 파일을 더블클릭하여 Chrome, Edge 등의 웹 브라우저에서 바로 모든 기능을 사용하실 수 있습니다.

## 📁 파일 구성
```text
새 폴더/
├── index.html         # 메인 포털 SPA 단일 페이지 마크업
├── css/
│   └── styles.css     # 모던 Glassmorphism UI, 애니메이션, 테마 스타일
├── js/
│   ├── data.js        # 한국공학대 실제 연구성과, 특허, 교수진, 지표 데이터셋
│   ├── charts.js      # Chart.js 기반 인터랙티브 통계 시각화 컨트롤러
│   └── app.js         # 검색, 필터, 모달, 북마크, 로컬스토리지 애플리케이션 로직
├── server.ps1         # .NET 기반 무설치 경량 로컬 HTTP 서버
├── start.bat          # 원클릭 서버 실행 및 브라우저 오픈 배치 파일
└── README.md          # 포털 소개 및 사용 가이드
```
